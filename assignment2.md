Chart 1

The visualization that I made displays the number of records for each license type. In the chart we can see multiple different bars which each correspond to a different license. I used a quantitative encoding on the y-axis in order to best represent the counts aggregated for each license type and a nominal encoding for the X-axis. I then sorted it by descending so we can see the largest count on the left. To me this was the most visually appearing as we can immediately see which license types have the greatest counts.This chart did not need any data transforming as we wanted to look at all the different license types in the dataframe.

Chart 2

This second chart that I made shows a scatterplot that shows the relationship beween issue dates and the license type. There are a bunch of scatter points and each point represents a specific license. We can hover over it and see when each individual license was obtained. I did a little bit of data transformation here where I changed the original issue date to a datetime as it was orignally a string. I then added a dropdown menu so that the user can select which license type they want to see. By doing this, we can see the years in which each license was obtained at a majority. I also made the non selected categories to be grey so that the main selected stands out.
